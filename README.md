# Shorts Guard

Android-прототип для лимита коротких видео. Ограничивает суммарное время YouTube, TikTok и Instagram за день, после чего показывает экран блокировки и принимает PIN владельца.

## Сборка APK

Откройте Actions → `build-apk` в GitHub и скачайте артефакт `shorts-guard-debug-apk`. Для публичной раздачи нужен GitHub Releases и подпись release-ключом.

## Установка и ограничения

1. Установите APK, задайте минуты и PIN.
2. Включите доступ к статистике использования.
3. Разрешите работу уведомления/фонового сервиса.

Android не позволяет приложению сделать себя физически неудаляемым. Для семейного сценария можно дополнительно оформить Device Owner через управляемое устройство; это требует сброса и настройки устройства администратором.
